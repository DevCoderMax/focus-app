# Plano: Aba "Metas" — Coach Pessoal de Estudos

## Visão Geral

Criar uma nova aba `/goals` que funciona como um **coach pessoal** — não apenas números e gráficos, mas um mentor que fala com o usuário em linguagem natural, detecta quando ele está parado, e incentiva o progresso contínuo. O foco é **detectar a falta de estudo e motivar a voltar**, não penalizar excesso.

**Filosofia:** "O maior inimigo do progresso não é estudar demais — é não estudar."

---

## 1. O Sistema de Frases Naturais (Coaching Engine)

O backend gera **frases contextuais** baseadas no estado real do usuário. Cada resposta do analytics inclui um campo `coachingMessage` com a frase do dia.

### Matriz de Frases por Estado

#### Usuário INATIVO (foco principal do sistema)

| Dias sem estudar | Tom | Exemplos de frases |
|---|---|---|
| 1 dia | Leve, gentil | "Você não estudou ontem. Tudo bem — mas não deixa virar costume. Uma página hoje já conta." |
| 2-3 dias | Direto, motivador | "Já faz 2 dias sem estudo. Cada dia que passa fica mais difícil voltar. Que tal 15 minutos agora?" |
| 4-7 dias | Urgente, encorajador | "Uma semana sem estudar. Seu cérebro já está esquecendo o que você aprendeu. Volte hoje — mesmo que seja pouco." |
| 8-14 dias | Preocupado, firme | "Duas semanas parado. O esquecimento é real. Mas não precisa recuperar tudo de uma vez. Comece pelo que é mais fácil." |
| 15+ dias | Direto, sem rodeios | "Você desapareceu. Seus tópicos estão empoeirando. Precisa de um choque de realidade? Você começou isso por um motivo." |

#### Usuário com BAIXA consistência (estuda, mas irregular)

| Padrão detectado | Tom | Exemplos |
|---|---|---|
| Estuda só 1-2x por semana | Incentivo | "Você está estudando, mas de forma irregular. 3 dias seguidos já mudam tudo. Tenta manter uma sequência?" |
| Só estuda à noite | Observação | "Seus melhores resultados são de manhã, mas você só estuda à noite. Experimentar acordar 30min mais cedo?" |
| Sessões muito curtas (<10min) | Conselho | "Sessões de 5 minutos não consolidam nada. Tenta subir pra 25min — um pomodoro completo." |
| Muitas sessões sem questão | Alerta | "Você está estudando mas não testando. Estudar sem questão é como dirigir sem olhar no espelho." |
| Só faz revisão, não estuda novo | Observação | "Revisão é ótima, mas você precisa de conteúdo novo também. Equilíbrio é a chave." |

#### Usuário CONSTANTE e EM PROGRESSO

| Métrica | Tom | Exemplos |
|---|---|---|
| Streak > 7 dias | Celebração | "7 dias seguidos! Você está construindo um hábito real. Continua assim." |
| Streak > 30 dias | Impacto | "30 dias de consistência. Você não é mais o mesmo pessoa que começou. Isso é transformação." |
| Melhoria na acurácia | Reconhecimento | "Sua acurácia subiu 12% esta semana. O método está funcionando." |
| Meta atingida | Celebração | "Meta batida! Mas não para aqui — o próximo nível te espera." |
| Dificuldade aumentando | Respeito | "Você está pegando matérias mais difíceis. Isso mostra coragem, não loucura." |

#### Usuário com SINAIS DE BURNOUT

| Sinal detectado | Tom | Exemplos |
|---|---|---|
| Sessões cada vez menores | Cuidado | "Suas sessões estão ficando mais curtas. Talvez seu corpo esteja pedindo um descanso. tá tudo bem parar 1 dia." |
| Muitas respostas em branco | Alerta | "Respostas em branco aumentando — isso pode ser sinal de cansaço mental. Que tal uma pausa mais longa hoje?" |
| Queda brusca após pico | Empatia | "Você teve uma semana ótima e depois caiu. Isso é normal — o descanso depois do esforço é parte do processo." |

## 2. Modelo de Dados

### Nova tabela `goals` no SQLite

```
goals
├── id (PK)
├── user_id (FK → users)
├── profile_id (FK → profiles)
├── title (TEXT NOT NULL)
├── description (TEXT)
├── goal_type (TEXT NOT NULL) -- 'study_time' | 'streak' | 'accuracy' | 'volume' | 'completion' | 'custom'
├── target_value (REAL NOT NULL)
├── current_value (REAL DEFAULT 0)
├── unit (TEXT) -- 'minutes' | 'days' | 'percent' | 'count'
├── subject_id (FK → subjects, nullable)
├── topic_id (FK → topics, nullable)
├── period (TEXT DEFAULT 'weekly') -- 'daily' | 'weekly' | 'monthly' | 'total'
├── start_date (TEXT NOT NULL)
├── end_date (TEXT)
├── status (TEXT DEFAULT 'active') -- 'active' | 'completed' | 'expired' | 'abandoned'
├── created_at (TEXT)
├── updated_at (TEXT)
```

### Índices
- `(user_id, profile_id, status)` — queries de metas ativas
- `(user_id, profile_id, goal_type)` — agrupamento por tipo

## 4. Backend — Endpoint de Analytics + Coaching Engine

### Endpoint: `GET /api/goals/analytics`

```
GET /api/goals/analytics
Header: X-Profile-Id: <id>

Response: GoalsAnalytics
```

#### Coaching Engine (Python) — Lógica de Seleção de Frase

```python
def generate_coaching_message(data: dict) -> CoachingMessage:
    days_idle = data['days_since_last_session']
    consistency_score = data['consistency_score']
    streak = data['current_streak']
    accuracy_trend = data['accuracy_trend']
    burnout_risk = data['burnout_risk']

    # PRIORIDADE 1: Usuário inativo (foco principal)
    if days_idle >= 15:
        return CoachingMessage(
            text="Você desapareceu. Seus tópicos estão empoeirando.",
            subtext="Comece por um tópico fácil. Só uma sessão para voltar ao ritmo.",
            tone="urgent", icon="AlertTriangle", accentColor="#ef4444"
        )
    elif days_idle >= 8:
        return CoachingMessage(
            text=f"Duas semanas sem estudar. O esquecimento já começou.",
            subtext="Volte hoje — mesmo que sejam 15 minutos. O importante é recomeçar.",
            tone="urgent", icon="Clock", accentColor="#f59e0b"
        )
    elif days_idle >= 4:
        return CoachingMessage(
            text=f"Já faz {days_idle} dias. Cada dia que passa fica mais difícil voltar.",
            subtext="Não precisa estudar muito. Só precisa começar.",
            tone="direct", icon="TrendingDown", accentColor="#f59e0b"
        )
    elif days_idle >= 2:
        return CoachingMessage(
            text=f"Você não estudou há {days_idle} dias.",
            subtext="Uma página hoje já quebra o ciclo. Tá ao seu alcance.",
            tone="gentle", icon="Coffee", accentColor="#9ca3af"
        )
    elif days_idle == 1:
        return CoachingMessage(
            text="Você não estudou ontem. Tudo bem — mas não deixa virar hábito.",
            subtext="Que tal uma sessão rápida hoje?",
            tone="gentle", icon="Sun", accentColor="#9ca3af"
        )

    # PRIORIDADE 2: Estudando, mas com problemas
    if burnout_risk in ('moderate', 'high'):
        return CoachingMessage(
            text="Seu corpo está pedindo um descanso.",
            subtext="Reduza a carga hoje. Dormir bem também é estudar.",
            tone="empathy", icon="Heart", accentColor="#a78bfa"
        )

    if data['blank_answer_rate'] > 0.3:
        return CoachingMessage(
            text="Muitas respostas em branco ultimamente.",
            subtext="Isso pode ser cansaço ou falta de confiança. Que tal revisar o básico primeiro?",
            tone="warning", icon="AlertCircle", accentColor="#f59e0b"
        )

    # PRIORIDADE 3: Usuário constante e progredindo
    if streak >= 30:
        return CoachingMessage(
            text=f"{streak} dias de consistência. Você se transformou.",
            subtext="Não é mais sobre motivação — é sobre identidade. Você é alguém que estuda.",
            tone="celebration", icon="Trophy", accentColor="#22c55e"
        )
    elif streak >= 14:
        return CoachingMessage(
            text=f"14 dias seguidos. Isso não é sorte — é disciplina.",
            subtext="Você está construindo algo que ninguém pode tirar de você.",
            tone="celebration", icon="Flame", accentColor="#22c55e"
        )
    elif streak >= 7:
        return CoachingMessage(
            text="Uma semana inteira! O hábito está se formando.",
            subtext="A maioria das pessoas desiste aqui. Você não é a maioria.",
            tone="celebration", icon="Zap", accentColor="#22c55e"
        )

    if accuracy_trend == 'rising':
        return CoachingMessage(
            text="Sua acurácia está subindo. O método está funcionando.",
            subtext="Continue assim — consistência vence talento.",
            tone="celebration", icon="TrendingUp", accentColor="#22c55e"
        )

    # PRIORIDADE 4: Estado neutro
    return CoachingMessage(
        text="Você está no caminho. Continue.",
        subtext="Não precisa ser perfeito — só precisa continuar.",
        tone="gentle", icon="ArrowRight", accentColor="#9ca3af"
    )
```

### Cálculos dos Analytics

**Consistency:**
- `currentStreak`: caminhar para trás contando dias com sessões
- `longestStreak`: varredura completa
- `daysSinceLastSession`: hoje - último `started_at` (crucial para coaching)
- `consistencyScore`: `min(100, (dias_estudados_30d / 30) * 100 * (1 + streak_bonus))`

**Motivation:**
- `overallScore`: média ponderada de frequência(30%), duração(20%), dificuldade(25%), melhoria(25%)
- `riskLevel`: `lastActivityDays > 5` → high, `> 3` → medium, senão low

**Mental State:**
- `blankAnswerRate`: `blankCount / (correct + wrong + blank)` — SINAL DE AVOIDANCE
- `burnoutRisk`: queda de duração + queda de frequência + aumento de branco
- `overallLabel`: mapear score → "Focado", "Estável", "Desacelerando", "Em Risco", "Precisa de Descanso"

## 9. Decisões de Design

| Decisão | Escolha | Motivo |
|---|---|---|
| Foco principal | Falta de estudo, não excesso | O maior problema dos estudantes é não estudar, não estudar demais |
| Frases no backend? | Sim | Permite mudar sem deploy, lógica centralizada |
| Tom das frases | Variável (gentil→urgente→celebração) | Se adapta ao contexto, não é robótico |
| CoachingBanner | Componente destacado no topo |Primeira coisa que o usuário vê — é o "hook" |
| Analytics computed no backend? | Sim | Mantém frontend leve |
| Meta pode ser por subject/topic? | Ambos (opcionais) | Flexibilidade |
| Burnout detectado | Cuidado, não penalidade | "Tá tudo bem parar" — empatia, não cobrança |
